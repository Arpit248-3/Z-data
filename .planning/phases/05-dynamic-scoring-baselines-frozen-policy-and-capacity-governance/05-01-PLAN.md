<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Scoring Input Quarantine | Feature payload must never include target label `isFraud`, raw `TransactionID`, or `TransactionDT` |
| Capacity Clearance Barrier | Capacity saturation must never silently convert high-risk or ambiguous escalations to `ROUTINE` |
| Workload Dimension Isolation | Synthetic review budget ($K=130$) must not be conflated with IEEE-CIS benchmark workload ($B_{\text{frac}} = M \cdot p_{\text{prev}}$) |
| Cohort Context Requirement | P5 budget ranking must never be evaluated on isolated single transactions without declared cohort context |
| Artifact Provenance | Scorer must strictly load and verify cryptographic SHA-256 hashes of model artifacts from `models/artifacts/ieee_cis_v1/` |
| Namespace Isolation | Real-data scoring and policy adapters live strictly in `integrations/ibm_architecture/`; canonical root synthetic policies are never overwritten |
| Holdout Partition Quarantine | Test partition (`split_hashes['test']`) is strictly held out from threshold tuning or policy selection |

## STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation |
|---|---|---|---|---|
| T-SCOR-01 | Elevation of Privilege | Feature Ingestion | Malicious request supplies `isFraud=0` to force low-risk routing | `_check_quarantine()` proactively raises `LeakageViolationError` before scoring |
| T-SCOR-02 | Information Disclosure | Scoring Output | Scorer inadvertently leaks model weights, internal training paths, or labels | Structured `ScoringResult` exposes only sanitized predictions and pseudonymous IDs |
| T-SCOR-03 | Denial of Service | Capacity Governor | Influx of fraud cases causes governor to drop high-risk alerts without trace | Excess cases shunted to `DEFERRED` / `R6` queue; audit metrics record deferred count |
| T-SCOR-04 | Tampering | Model Bundle | Attacker modifies serialized model weights on disk | `load_bundle()` verifies streaming SHA-256 checksums against signed manifest |
| T-SCOR-05 | Repudiation | Policy Decisions | Decisions made without recording exact policy version or threshold config | Every `ScoringResult` binds immutable `policy_version`, `model_version`, and `reason` |
| T-SCOR-06 | Denial of Service / Integrity | Capacity Governor | Applying synthetic $K=130$ budget to 118,108 test cases starves benchmark | Governor supports explicit `budget_fraction` and validates cohort dimensions |
| T-SCOR-07 | Information Disclosure / Integrity | Threshold Tuning | Using test partition labels to tune router thresholds invalidates holdout | Threshold tuning restricted strictly to validation partition (`split_hashes['validation']`) |
</threat_model>
