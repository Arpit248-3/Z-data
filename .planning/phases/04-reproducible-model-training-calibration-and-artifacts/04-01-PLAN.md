<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Model Input Quarantine | Feature matrix must never include target label `isFraud`, raw `TransactionID`, or `TransactionDT` |
| Partition Fitting Governance | Estimators fit on train split only; calibrator fits on calibration split only; validation/test are strictly forbidden from fitting |
| Training Integrity & Fallback | Pipeline must fail closed if raw CSVs are missing; never fabricate model weights or claim real-data benchmarks succeeded |
| Resource Safety Gate | Pre-stage RAM guard prevents starting training if available physical RAM < 4.5 GB floor |
| Namespace Isolation | Real-data model artifacts live strictly in `models/artifacts/ieee_cis_v1/`; root canonical synthetic models are never overwritten |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Information Disclosure | Feature Preprocessing / Input Matrix | critical | mitigate | `FeaturePipeline.validate_features()` raises `LeakageViolationError` on target/ID columns |
| T-04-02 | Elevation of Privilege | Calibration Fitting | high | mitigate | `validate_calibration_partition()` rejects `"validation"` and `"test"` with `ValueError` |
| T-04-03 | Tampering | Dataset Fallback / Fake Model Weights | high | mitigate | `trainer.train_pipeline()` fails closed with `ArtifactNotFoundError` when `data/raw/` is absent |
| T-04-04 | Tampering | Synthetic Model Overwrite | high | mitigate | Isolate all serialized artifacts to `models/artifacts/ieee_cis_v1/`; root models remain untouched |
| T-04-05 | Repudiation | Model Bundle Provenance | high | mitigate | Compute SHA-256 checksums over all serialized artifact files in `model_bundle_manifest.json` |
| T-04-06 | Denial of Service | Memory Exhaustion / OOM Thrash | high | mitigate | Sequential estimator fitting, `n_jobs=1` on ExtraTrees, `gc.collect()`, and dynamic RAM check floor (6.0 GB) |
</threat_model>
