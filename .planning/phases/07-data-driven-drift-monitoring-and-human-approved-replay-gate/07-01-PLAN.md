  - Failed validation, timeout, or malformed proposals fail closed, leaving the active production policy completely intact.

         * `act_sample_count: int`
         * `ref_missing_rate: float`

         * `report_id: str`
         * `reference_window_id: str`
         * `comparison_window_id: str`
         * `features_monitored: int`
         * `significant_drift_features: int`
         * `moderate_drift_features: int`

         * `notice: str` (Mandatory discipline notice)
    2. Implement `DriftMonitor`:
       - `calculate_psi(reference, actual, bins=10, epsilon=1e-4)`: quantile binning on reference distribution, epsilon smoothing for empty bins, sums `(act - ref) * ln(act / ref)`. Handles non-finite and constant inputs gracefully.
       - `calculate_ks(reference, actual)`: two-sample Kolmogorov-Smirnov test via `scipy.stats.ks_2samp`.
       - `calculate_wasserstein(reference, actual)`: 1D Earth Mover's Distance via `scipy.stats.wasserstein_distance`.
       - `compute_feature_drift(reference, actual, feature_name)`: calculates combined PSI, KS, Wasserstein, and missingness metrics.
       - `compute_score_drift(reference_scores, actual_scores)`: calculates distribution drift on calibrated posterior probability $p$.
       - `compute_drift_report(reference_df, comparison_df, features, ref_id, comp_id, status, ref_scores=None, act_scores=None)`:
         * Strict Ground-Truth Quarantine: Proactively filters and rejects `isFraud`, `target`, `label`, `TransactionID`, and `TransactionDT`.
         * Calculates summary metrics: `mean_psi`, `max_psi`, counts of significant and moderate features, and `score_drift`.
         * Generates deterministic SHA-256 `provenance_hash` over canonical report representation.
         * Binds mandatory notice: "Distribution monitoring indicators (PSI/KS/Wasserstein) quantify covariate shift and do not constitute proof of fraud or policy failure."
  </action>

    3. Implement `ReplayGate`:
       - `validate_and_replay(proposal, current_policy, validation_data, scenario_id="validation", scoring_service=None)`:
         * Schema & hash check: validates `proposal.base_cfg_hash == current_policy.compute_hash()`.
         * Allowlist check: verifies proposed changes contain only `ALLOWLISTED_POLICY_KEYS`.
         * Bounds check: verifies $0.0 < t_{\text{review}} < t_{\text{alert}} \le 1.0$ and valid ranges.

       - `approve_proposal(proposal_id: str, approver: str, rationale: str, audit_chain=None) -> Dict[str, Any]`:
         * Enforces proposal must be in `AWAITING_HUMAN_APPROVAL`.
         * Validates authenticated human approver ID (must be non-empty string).
         * Transitions proposal status to `APPROVED`.
         * Cryptographically seals approval decision into `AuditChain`.
       - `reject_proposal(proposal_id: str, reviewer: str, reason: str, audit_chain=None) -> Dict[str, Any]`:
         * Transitions proposal status to `REJECTED`.
         * Active policy remains 100% unchanged.
