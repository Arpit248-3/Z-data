<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Ground-Truth Feature Quarantine | Target `isFraud`, raw `TransactionID`, and `TransactionDT` must never enter the model feature matrix or feature manifests |
| Dataset Source Integrity | Real-data loader must fail closed if raw IEEE-CIS files are missing; never substitute synthetic fixture rows or relabel synthetic data |
| Real-Data Namespace Isolation | All real-data manifests and validation reports must live under `results/ieee_cis_v1/`; never overwrite root canonical synthetic result files |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Information Disclosure | Data Loader / Feature Matrix | critical | mitigate | Strip `isFraud` by default; raise `LeakageViolationError` if target or raw IDs enter feature vectors |
| T-03-02 | Tampering | Dataset Fallback | high | mitigate | Fail closed with `ArtifactNotFoundError` when `data/raw/` is missing; forbid silent synthetic fallback |
| T-03-03 | Tampering | Split Manifests | high | mitigate | Store real IEEE-CIS manifests in `results/ieee_cis_v1/`; preserve root `results/split_report.json` |
| T-03-04 | Repudiation | Partition Hashing | high | mitigate | Deterministically hash partition ID sequences using SHA-256 (`compute_partition_hash`) |
</threat_model>
