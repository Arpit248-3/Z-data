<task id="2" name="Implement and Execute Matched-Capacity Paired Bootstrap Benchmark Suite" type="execute">
  <description>
    Implement `integrations/ibm_architecture/evaluation/benchmark_runner.py` and CLI script `scripts/run_ieee_benchmark.py`:
    1. Load test partition (118,108 transactions, 4,064 frauds) with strict ground-truth quarantine during scoring.
    2. Evaluate Baseline B2 (`B2TopBudgetBaselineAdapter`) and Candidate P5 (`P5CandidatePolicyAdapter`) across registered budget multiples (1.0x, 1.5x, 2.0x, 3.0x).
    3. Compute core metrics: recall, precision, touched rate, caught fraud, missed fraud, denominators (118,108 rows, 4,064 frauds), PR-AUC, ECE calibration error, confident misses, and deferrals.
    4. Execute 1,000 paired bootstrap resamples (seed 42, 95% empirical percentile CI: `[ci_lower, ci_upper]`) evaluating difference $\Delta = \text{Recall}(P5) - \text{Recall}(B2)$.
    5. Evaluate shift scenarios S0 (nominal), S1 (prevalence burst), S2 (covariate shift), and S3 (unseen feature perturbation, strictly marked `SYNTHETIC_SHIFT`).
    6. Measure host AMD64 CPU inference latency with warm-up (single-transaction p50, p95, p99; batch-of-32 p95).
    7. Score acceptance criteria AC1–AC5 with truthful adherence to the master specification (AC1 recall gain and AC2 workload reduction reported factually as UNMET under frozen $\lambda=0.0$; AC3 shift robustness and AC5 latency reported as PASS).
    8. Persist structured results to `results/ieee_cis_v1/benchmark_results.json`.
  </description>
