<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Agent Sanitization Barrier | Agents receive only sanitized `AgentCaseView`; raw features, target labels, and transaction IDs are prohibited |
| Operational Independence Barrier | Agent advice is strictly non-authoritative; agent failures cannot alter deterministic action routing |
| Claim Grounding Barrier | Agent proposals are strictly unverified claims until evaluated deterministically by `ClaimVerifier` |
| Proposal Isolation Barrier | Policy change suggestions are inert `Proposal` objects; they cannot mutate active policies without human authorization |
| Ledger Immutability Barrier | Decision records are cryptographically sealed with previous-hash linkage and HMAC signatures |
| Secret Key Isolation | HMAC keys are loaded exclusively from environment variables (`SIGNALGATE_AUDIT_KEY`) and never committed |
| Namespace Isolation | Real-data audit records persist to `results/ieee_cis_v1/audit_chain.jsonl`; synthetic logs (`logs/audit.jsonl`) remain untouched |

## STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation |
|---|---|---|---|---|
| T-AGNT-01 | Elevation of Privilege | Agent Copilot | Malicious prompt injection causes LLM to override deterministic FRAUD_ALERT to ROUTINE | Deterministic routing is executed before agent invocation; Copilot output is strictly advisory |
| T-AGNT-02 | Information Disclosure | Agent Case View | Agent prompt exposes raw 391-feature vectors or client identifiers to external LLM API | `AgentCaseView` enforces strict allowlist; `check_for_quarantine_violations()` blocks leakage |
| T-AGNT-03 | Denial of Service | LLM Provider | Remote LLM endpoint times out or errors, stalling the scoring and audit pipeline | `ConfigurableLLMProvider` enforces 5s timeout and falls back to `OfflineTemplateProvider` |
| T-AGNT-04 | Tampering | Audit Ledger | Insider modifies audit entry on disk to conceal an altered fraud routing decision | `verify_chain()` detects broken `prev_hash` linkage and invalid HMAC signatures |
| T-AGNT-05 | Repudiation | Claim Generation | Agent generates false or hallucinated rationale that is presented as verified fact | `ClaimVerifier` evaluates claims against source facts; false claims are rejected and logged |
| T-AGNT-06 | Information Disclosure | Secret Key Handling | Hardcoded or committed HMAC secret key compromises audit authentication | Keys loaded strictly from `SIGNALGATE_AUDIT_KEY` env var; missing keys report as unavailable |
| T-AGNT-07 | Elevation of Privilege | Policy Proposals | Agent or drift sentinel automatically modifies active triage thresholds | Changes restricted to inert `Proposal` records; activation requires replay and human authorization |
</threat_model>
