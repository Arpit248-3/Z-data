<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Ground-Truth Quarantine | Target `isFraud`, raw `TransactionID`, and `TransactionDT` must never cross into model feature matrices, scoring feature forms, `AgentCaseView`, or LLM prompts |
| Evidence Mode Boundary | Requests for real-data benchmark mode must fail closed if data/artifacts are missing; must never silently downgrade to synthetic data |
| Namespace Isolation | `integrations/ibm_architecture/` must not overwrite, mutate, or intercept existing root packages or FastAPI configurations |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Information Disclosure | `AgentCaseView` | critical | mitigate | Enforce `model_config = ConfigDict(extra="forbid", frozen=True)` and pre-validators raising `LeakageViolationError` on `isFraud`, `TransactionID`, `TransactionDT` |
| T-02-02 | Tampering | Mode Resolution | high | mitigate | Mode registry must fail closed with explicit diagnostic errors; never fall back silently to synthetic fixtures |
| T-02-03 | Repudiation | `AuditRecord` | high | mitigate | Enforce SHA-256 regex (`^[0-9a-f]{64}$`), timezone-aware timestamps, and deterministic record hash calculation |
| T-02-04 | Tampering | Root Codebase | high | mitigate | Build exclusively inside `integrations/ibm_architecture/`; do not modify root `models/`, `data/`, or `backend/` packages |
</threat_model>
